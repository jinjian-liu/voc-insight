# VoC Insight v0.1.0

第一个可体验版本，已经打通“反馈收集 → AI 分析 → 人工确认 → 问题管理 → 处理完成 → 数据复盘”的核心闭环。

## 主要功能

- 文本反馈录入；
- CSV/XLSX 批量导入；
- DeepSeek 结构化分析；
- 摘要、分类、关键词、严重程度及优先级；
- 分析结果人工编辑和确认；
- 相似问题推荐；
- 创建问题或关联已有问题；
- 问题处理结果和操作时间线；
- 自定义问题分类；
- ECharts 数据看板；
- Windows 单文件 EXE。

## Windows 使用方式

1. 下载 `VoC-Insight-Windows-x64.exe`；
2. 双击运行，应用会自动在默认浏览器打开；
3. 填写操作人名称和自己的 DeepSeek API Key；
4. 通过 Windows 系统托盘图标重新打开或退出应用。

数据默认保存在 `%LOCALAPPDATA%\VoCInsight\voc.db`。

## 注意事项

- 本版本未进行商业代码签名，Windows SmartScreen 可能显示未知发布者；
- 系统不提供账号和权限控制，请在个人电脑或可信内部环境使用；
- API Key 仅保存在运行内存中，关闭程序后清除；
- 使用真实业务反馈前，请确认企业的数据脱敏及第三方模型合规要求。
